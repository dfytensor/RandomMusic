# 歌词可唱性评价与创作体系 v4.2（实证版）

日期: 2026-10-17  状态: 3 首证明点验证通过（05 追平 / 08 大胜 / 04 待测）

## 1. 实证链（为什么推翻 v3）

| 实验 | 结论 |
|---|---|
| v3 韵律分（押韵/平仄/对句/整齐）vs 渲染 v3.5 | Spearman ρ=0.077 ≈ 零相关 |
| 同 seed A/B（v3 韵文词 vs 旧词，12 首） | 平均 **-17.7**（10负1平1胜）→ v3 韵文有害 |
| 05 同 seed 对照（v4.2 词 85% 同旧词） | 仍 -23.9 → **单 seed A/B 方法无效** |
| 05 多 seed 分布对比 | v4.2 词 top 81.3 ≥ 旧词 81.2 |

**核心认知**：
1. YuE2 是自回归混沌系统——词的任何微小改动都会级联改变整条生成轨迹，固定 seed ≠ 控制变量。
2. 词效应必须用**分布口径**（≥5 seed）测量；单 seed 差异是噪声（±20）。
3. 文本韵律（诗律）≠ 歌唱性。五绝不是校准金标，"旧词渲染好"才是。

## 2. v3 韵文为什么失败（诊断）

- 全篇 7 字等长（cv 0.05-0.24）→ 模型失去乐句呼吸线索（Δcv 与 AB 差相关 +0.46）
- 单韵到底 + 每句入韵 → 单调（12 号全篇江阳 → -19）
- 格言化改写丢失叙事细节（"隔壁咳嗽停了半拍"→"隔壁咳嗽都咽尽"）
- 词的面貌从"现代歌词"漂移到"韵文"，超出模型舒适区

## 3. v4.2 评价器（lyrics_prosody_v4.py）

| 维度 | 权重 | 说明 |
|---|---|---|
| 对句押韵率 | 0.15 | 偶句入韵即可；**单韵到底不加分**（rhyme 取 pair 不取 dom） |
| 句尾平仄相异 | 0.10 | 相邻行末字平仄不同 |
| 对句等长 | 0.10 | 仅 Verse+Pre-Chorus |
| 常用字率 | 0.10 | CJK 扩展区视为生僻 |
| 开口韵占比 | 0.15 | 段主辙开口度（发花/江阳/遥条/言前 响亮 > 衣期/姑苏 闷） |
| 具象密度 | 0.15 | jieba 名词+动词占比，/0.65 封顶（实证 ρ=0.41 最强文本因子） |
| 行长变化度 | 0.15 | cv∈[0.12,0.45] 满分——奖励乐句呼吸，惩罚韵文化 |
| 辙多样性 | 0.10 | strict 段主辙数 ≥3 满分——惩罚一韵到底 |

预测力演进: v3=0.077 → v4=0.154 → v4.1=0.483 → v4.2=0.462（express_mean 口径，n=12）

**定位修正**：评价器只做同曲多版本的**相对排序**，绝对分不设达标线；最终裁决 = v3.5 音频分。

## 4. v4.2 创作纪律（旧词为体、格律为用）

1. **不从零写**：在旧词上做最小修改（保 85% 意象与叙事细节）
2. 对句等长（对句间允许 6-10 字变化）
3. 偶句入韵，段内一辙；**段间换辙**；韵脚选开口辙常用字
4. 句尾平仄相异（允许 ≤1 处破格）
5. 钩子句/副歌 hook **一字不动**（剁手魔/月供日/药比蜜甜）
6. 保留全部 [结构] 与 (build)/(breathy)/(whisper) 表演标记
7. 禁格言体：每行必须含具体名词/动作
